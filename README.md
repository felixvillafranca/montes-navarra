# Montes de Navarra

Visor 3D del relieve de Navarra y el Pirineo occidental: cimas, pueblos, ríos, carreteras, pistas y senderos, con condiciones del ensemble GEFS por cima.

**Montes a la vista** (realidad aumentada): https://felixvillafranca.github.io/montes-navarra/ar/ — apunta la cámara al horizonte y etiqueta las cimas visibles.

En el móvil, «Mi posición» usa el GPS y «Girar con el móvil» la brújula del teléfono.

Datos: elevación Mapzen Terrarium (SRTM/EU-DEM); cimas, pueblos, ríos y vías © colaboradores de OpenStreetMap (vía Overpass y Geofabrik); meteorología GEFS vía Open-Meteo.
